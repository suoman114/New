# 묵음 Packet (AMR / AMR-WB) — 부록 7

> 출처: "녹취(uVCS) 설계서 부록 7".
> 담당: `rtp-media`(DTX 삽입), `validator`(`write_mute` 기준값).
> SID/NO_DATA/SPEECH_LOST → 아래 FT별 고정 byte 열로 묵음 frame 을 기록한다.
> `write_mute(count, zWB, nMaxModeset)` 는 `nMaxModeset` 에 해당하는 FT 의 byte 열을 `count` 만큼 기록.
