# H.264 Decoding / De-Interleaving 규격 (2차 범위)

> 출처: "녹취(uVCS) 설계서 부록 8~9".
> 1차 범위는 음성(AMR-WB)이며, 영상 녹취 생성은 2차. 단 검증기 인터페이스는 확장 가능하게 둔다.
> 담당: `rtp-media`(2차 송출), `validator`(2차 검증).

## 1. Decoding rule (부록 8)

### Single NAL Unit mode & Non-Interleaved mode
- 수신 순서대로 buffer 저장.
- 손실 DPA 감지 시 연관 data partition B, C drop.
- 손실 FU 발견 시 연관 모든 FU drop.
- `NRI=0` 인 모든 NALU drop.
- RTP sequence number 순서대로 packet 해제.
- Single NAL unit → 바로 decoder. STAP-A → capsulation 순서대로. FU-A → 전송 순서대로 합친 후 decoder.

### Interleaved mode
- 수신 순서대로 de-interleaving buffer 저장.
- Aggregation packet 은 개별 NAL Unit 별 DON 계산하여 저장.
- 손실 FU 식별 시 이후 연관 FU 모두 drop. `NRI=0` NALU drop.
- decoder 이동 기준:
  - N개 이상 NAL units 존재 시 N-1 될 때까지 수행.
  - `sprop-max-don-diff` 존재 시 `don_diff(m,n) > sprop-max-don-diff` 인 모든 NAL unit.
  - DON distance 순으로 decoder 전달(동일 시 임의 순서 가능).
- RTP session 초기화 시 `PDON=0`.
- DON distance:
  ```text
  if (NAL unit의 DON > PDON)  DON distance = DON - PDON
  else                        DON distance = 65535 - PDON - DON + 1
  ```
- 모든 packet DON distance 계산 후 `PDON` = decoder 전달 마지막 NAL unit 값.

## 2. De-Interleaving Buffer (부록 9)
- `sprop-deint-buf-req` / `deint-buf-cap` 로 buffer size 명시 가능.
- 상태: initial buffering → buffering-while-playing. 전환 조건(하나라도 만족):
  - de-interleaving buffer 에 N개 이상 VCL NAL units (N=`sprop-interleaving-depth`).
  - `sprop-max-don-diff` 존재 & `don_diff(m,n) > sprop-max-don-diff` (n=최대 AbsDON, m=최소 AbsDON).
  - initial buffering 유지시간 ≥ `sprop-init-buf-time`.

### Function AbsDON
```text
첫 전송 NAL unit: AbsDON(0) = DON(0)
m, n = 연이어 전송된 NAL unit
If   ( DON(m) == DON(n) )  AbsDON(n) = AbsDON(m)
elif ( DON(m) <  DON(n) )
     if ( DON(n)-DON(m) < 32768 ) AbsDON(n) = AbsDON(m) + DON(n) - DON(m)
     else                          AbsDON(n) = AbsDON(m) - (DON(m) + 65536 - DON(n))
else
     if ( DON(n)-DON(m) < 32768 ) AbsDON(n) = AbsDON(m) - (DON(m) - DON(n))
     else                          AbsDON(n) = AbsDON(m) + 65536 - DON(m) + DON(n)
```

### Function don_diff(m,n)
```text
If   ( DON(m) == DON(n) )  don_diff = 0
elif ( DON(m) <  DON(n) )
     if ( DON(n)-DON(m) < 32768 ) don_diff =  DON(n) - DON(m)
     else                          don_diff = -(DON(m) + 65536 - DON(n))
else
     if ( DON(n)-DON(m) < 32768 ) don_diff = -(DON(m) - DON(n))
     else                          don_diff =  65536 - DON(m) + DON(n)
```
